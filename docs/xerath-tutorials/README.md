# Xerath School

Six short narrated tutorials for the Xerath path, about a minute each. Watch
one, then play the mode it names under **PRACTICE › XERATH**.

1. [**Arcanopulse** — let go, Kurbo](ep1-arcanopulse.mp4) · 1:07 · the charge is the range; release the moment the line reaches, and lead the half second.
2. [**Eye of Destruction** — the future is round](ep2-eye.mp4) · 0:55 · it lands 0.75s late; put the centre where they are walking.
3. [**Shocking Orb** — distance is damage](ep3-orb.mp4) · 0:52 · 0.75s stun point blank, 2.25s at full range; minions block it.
4. [**Spacing** — live in the band](ep4-spacing.mp4) · 1:18 · threat ranges, your 1450, and the floor between them.
5. [**The combo** — stun, then everything](ep5-combo.mp4) · 0:47 · a stunned body cannot juke: orb, Eye, pulse.
6. [**Rite of the Arcane** — long-distance relationships](ep6-rite.mp4) · 0:51 · four shots, four different guesses, and be safe before you root.

Made from `tools/tutorials/` — see the README there to change a line and
rebuild.
